# Application Android RCR

Dossier unique de l'application. L'APK se compile dans GitHub (onglet **Actions → Build Android APK → Run workflow**),
puis se télécharge dans **Artifacts → rcr-apk**. Aucune clé ni aucun secret à configurer.

Adresse de l'API : `https://rcr.cd/api/v1` (modifiable via la variable GitHub `API_BASE`).
Installation : désinstaller l'ancienne version avant d'installer la nouvelle (signature de test).
